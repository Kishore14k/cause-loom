# AI Usage Disclosure

## Project authorship

Causeloom is my original project idea. I defined the problem, designed the service dependency graph model, and architected and developed the Java/Spring Boot backend. The core backend and FalkorDB implementation are my own work.

## How I used AI

### Learning and technical guidance

During development, I used AI to help me learn Cypher, understand graph queries, and learn how to integrate FalkorDB with Spring Boot. This assistance supported my understanding while I implemented the backend and graph functionality.

### Frontend development

AI assisted with generating and refining Angular frontend code, including components, styling, API integration and graph visualization. I provided the project requirements, design direction and architectural guidance, including a practice project as a structural reference. AI also helped refactor the frontend into a more maintainable feature-based structure.

### Visual assets and documentation

AI assisted with creating the Causeloom logo and its SVG variants, and with drafting this disclosure from my description of the development process.

## Responsibility

I take responsibility for the submitted project and its use of AI-assisted code and assets. The project concept, graph model, backend architecture and core backend/FalkorDB implementation remain my contributions; AI assistance was used for learning, frontend development, visual assets and documentation as described above.
